1-Technologies & Tools Used
Svelte

A lightweight and modern framework for building user interfaces. It compiles at build-time, resulting in fast performance and minimal bundle size.

Vite

A high-speed development tool used for running the project locally and building optimized production files.

HTML

Used to structure the main layout and content of the website.

CSS

Used for styling the interface, handling layouts, colors, and typography.
Also includes custom CSS Keyframes animations for specific motion effects.

JavaScript

Handles interactive behaviors and logic inside Svelte components.


2-Libraries Used
GSAP

A powerful animation library used to create smooth, professional, and highly customizable animations across the website.

AOS (Animate On Scroll)

A ready-to-use scroll animation library that triggers visual effects when elements enter the viewport.


3-Responsiveness

The website is fully responsive and adapts seamlessly to all screen sizes:

Mobile devices

Tablets

Desktop screens

Layouts and component structure are clean, organized, and easy to maintain, ensuring a consistent experience across all devices.
